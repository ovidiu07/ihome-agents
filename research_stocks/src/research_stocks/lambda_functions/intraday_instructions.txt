## INPUTS (always supplied via S3 URLs)

1. `previous_daily_report_md` – the full markdown report generated pre-open today (contains three sections).
2. `intraday_json` – the latest minute/5-minute/15-minute JSON snapshot for the *same* symbol, captured mid-session.

You must fetch both and treat them as the *entire* data source.

### JSON structure

Identical to the morning-report spec (`fintech_one_minute`, `fintech_five_minutes`, `fintech_fifteen_minutes`, …).
All keys are constant; values reflect the latest intraday state.

## YOUR TASKS

### 0 — Parse the baseline open

* From `previous_daily_report_md`, locate **SECTION 1**.
* Read the `current_day.open` value **only**; call it `OPEN_BASE`.
* **Do not change **\`\`** under any circumstance.**

### 1 — Predict today’s H-L-C based on new data(but keep the open)

* Use `intraday_json.fintech_one_minute.candles` up to the last timestamp defined by **last\_updated\_utc**.

  * `HIGH_NEW`  = maximum of `h` array to **last\_updated\_utc**.
  * `LOW_NEW`   = minimum of `l` array to **last\_updated\_utc**.
  * `CLOSE_NEW` = last element of `c` array (same index as **last\_updated\_utc**).
* In **SECTION 1** of the output, replace the original `"high"`, `"low"`, `"close"` with these refreshed values; leave `"open"` = `OPEN_BASE`.
* Weekly forecast may be re-estimated if your model logic deems intraday data material; otherwise leave as is.

### 2 — Augment the step-by-step trading plan

Using all intraday timeframes (1-, 5-, 15-minute):

1. Re-calculate support/resistance clusters, VWAP, OBV, short-term ATR, and any newly emerged patterns or divergences.
2. Comment on volume-price behaviour since the open, highlighting anomalies (e.g. high-tick washouts, OBV divergences).
3. Add *actionable* trade ideas that exploit these fresh levels, including precise entries, stops, targets, and trailing logic.
4. Keep the prose under **\~650 words**.
5. Where previous advice is **invalidated** by current price action, explicitly say so and replace with updated guidance.

### 3 — Trim the intraday execution plan to the future only

* Determine the current epoch based on **last\_updated\_utc** (UTC) and standard US-equity session segments:

  | Epoch       | UTC reference |
  | ----------- | ------------- |
  | Pre-Open    | 12:00–13:29   |
  | Open Range  | 13:30–14:00   |
  | Mid-Morning | 14:00–16:00   |
  | Lunch       | 16:00–18:00   |
  | Afternoon   | 18:00–19:30   |
  | Close       | 19:30–20:00   |

* \*\*Only output bullets for the epoch ***after*** the one containing \*\***last\_updated\_utc**\*\* (inclusive of that epoch if it hasn’t finished).\*\*

* Use the same bullet format (`Trigger`, `Entry`, `Stop-loss`, `Profit-target`, `AI position`) but skip any epochs already completed.
