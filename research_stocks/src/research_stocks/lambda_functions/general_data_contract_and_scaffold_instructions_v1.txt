## Bias computation (deterministic)
### 1) Score each non-neutral signal (by TF)
- Use each TF block’s `signals[]`. Map bull → +1, bear → −1, neutral → 0 using the rules above.

### 2) Class weights (by indicator family)
- Trend/MA = 0.30 (SMA/EMA/WMA/DEMA/ADX/DI/DM/SAR/AROON)
- Momentum = 0.25 (RSI/MACD/MACDEXT/MOM/ROC/ROCR/TRIX/CMO/ULTOSC)
- Oscillators = 0.15 (STOCH/STOCHF/STOCHRSI/WILLR/CCI/MFI)
- Volume/Flow = 0.10 (OBV/AD/ADOSC/BOP)
- Volatility/Regime = 0.20 (ATR/NATR/BBANDS bandwidth, TRANGE, DX)

### 3) Timeframe weights
- wD = 0.50, wH = 0.30, wW = 0.20.
- 1m is **excluded** from S (weight = 0). Use 1m only as a tie‑breaker for entry timing and micro‑structure confirmations.
- If Weekly missing → wW=0.00 and print the note under the audit.
- If Daily ADX≥25 and Hourly ADX<25: amplify Daily group by ×1.15; if Hourly ADX≥25 and Daily ADX<25: amplify Hourly group by ×1.15.

### 4) Compute S (−1…+1)
- For each signal: signed_score = (+1 or −1) × class_weight × TF_weight.
- Sum all signed_scores, normalize by the max possible sum for present signals, clip to [−1, +1].
- Output: `Bias score S = <value> → {Bullish if S>0.25 | Neutral if −0.25≤S≤0.25 | Bearish if S<−0.25}`.
- Also list **Top 5 drivers by absolute contribution** as `name@TF`.

## Forecast Engine (today only; OHLC for the daily bar)
We forecast `{open, high, low, close}` for **today’s daily bar** using the aggregated JSON:

1) **Baselines**
   - O₀ = `next_prediction_from_finnhub.daily.open` if present else prior PCLOSE (if available in aggregated data); else use nearest Daily price proxy from the JSON.
   - C₀ = prior Daily close if present; else the nearest available proxy.
   - R_base = ATR_D14 × regime_factor (derived from volatility context if exposed; else default 1.0).

2) **Apply bias S (directional tilt)**
   - CLOSE = C₀ + sign(S) × min(0.40×ATR_D14, |S|×0.60×ATR_D14).
   - OPEN: if pre-market exists, shift O₀ toward pre-market direction by ±min(0.25×ATR_D14, |GAP|); else OPEN=O₀.

3) **Distribute range around O/C (bounded)**
   - Upside share u = 0.5 + 0.3×max(S,0) (clip 0.35–0.80)
   - Downside share d = 0.5 + 0.3×max(−S,0) (clip 0.35–0.80)
   - HIGH = max(OPEN, CLOSE) + u × R_base
   - LOW  = min(OPEN, CLOSE) − d × R_base

4) **Clamps & sanity**
   - HIGH ≥ max(OPEN,CLOSE); LOW ≤ min(OPEN,CLOSE)
   - (HIGH−LOW) ≤ 2.2×ATR_D14
   - If Weekly trend opposes S strongly (|S|>0.5), reduce the against-trend side by 20–40%.
   - R_base must originate from ATR_D14 × regime_factor. If ATR_D14 is missing, print “R_base: no data” and OMIT any computations that require R_base (do not substitute prior-day true range or any proxy).

5) **Weekly forecast (current week)**
   - Blend Weekly levels/patterns with Weekly signals (0.6/0.4). Clamp total range ≤ 1.8×ATR_W14 and do not violate already printed weekly highs/lows.
