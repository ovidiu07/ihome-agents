PRE-OPEN DAILY FORECAST CONTRACT — v3.5 (2025-08-08)

## Scope & Inputs (no other data allowed)
- data: single JSON with blocks:
  • fintech_daily, fintech_hourly, fintech_weekly (schema: last_updated_utc; candles {o,h,l,c,v,t}; patterns[]; support_resistance.levels[]; aggregate_indicator; technical_indicators)
  • optionally fintech_one_minute/five_minutes/fifteen_minutes (used ONLY for pre-market GAP classification if t < 13:30 UTC)
  • next_prediction_from_finnhub.daily / weekly (+ component_forecasts)
- Report is **pre-open** and forecasts **today’s daily bar** only. Intraday patterns (1/5/15m) are *not* used other than gap bias.

## Market session & timestamps
- US equities RTH: 13:30–20:00 UTC. “Today” = data.current_date (UTC aware).
- Any intraday candle on current_date with t < 13:30 UTC is **pre-market**.

## Anchors
- PCLOSE = last complete **daily** close before current_date.
- If pre-market exists: PREMKT_LAST = last pre-open close; GAP = PREMKT_LAST − PCLOSE; else "no data".
- ATR_D14 = daily ATR(14); ATR_W14 = weekly ATR(14). If missing, "no data".

## Indicator Audit (D/H/W) — table
Create a Markdown table named **Indicator Audit (D/H/W)**:

Indicator | D last | D dir | H last | H dir | W last | W dir | Signal

- “last”: most recent primary-field value up to the latest bar for that TF (rounded).
- “dir”: slope over the last 3 points → {rising, falling, flat}; if <2 points → "no data".
- **Signal rules (deterministic)**:
  • RSI: >55 bull; <45 bear; else neutral
  • MACD/MACDEXT: macdHist>0 bull; <0 bear; else neutral
  • STOCH/STOCHF/STOCHRSI: k>d and k rising → bull; k<d and k falling → bear; else neutral (if d missing, k>55 bull, k<45 bear)
  • WILLR: >−20 bull; <−80 bear; else neutral
  • ADX/ADXR: <20 neutral; ≥20 → +DI>−DI bull; −DI>+DI bear; if DI missing → neutral
  • DI/DM: PLUSDI>MINUSDI & PLUSDM>MINUSDM → bull; inverse → bear; else neutral
  • MFI: >55 bull; <45 bear; else neutral
  • CCI: >+100 bull; <−100 bear; else neutral
  • MOM/ROC/ROCR/TRIX: primary>0 & rising → bull; <0 & falling → bear; else neutral
  • ULTOSC: >50 bull; <45 bear; else neutral
  • AROON/AROONOSC: aroonup>70 & aroondown<30 → bull; reverse → bear; else neutral
  • MA family (SMA/EMA/WMA/DEMA): close_TF > MA & MA rising → bull; close_TF < MA & MA falling → bear; else neutral
  • BBANDS: close>middle & (upper−close)<(close−lower) → bull; close<middle & (close−lower)<(upper−close) → bear; else neutral
  • SAR: close above SAR → bull; below → bear
  • OBV/AD/ADOSC: rising 3 pts with price up → bull; falling with price down → bear; else neutral
  • ATR/NATR/TRANGE/MIDPOINT/MIDPRICE/DX: neutral (range/regime only)

If an indicator exists in JSON but is not shown → after the table print:
⚠ Coverage gap: missing rows for: name@TF, ...

## Bias computation (deterministic)
### 1) Score each non-neutral signal
- Map bull → +1, bear → −1 (neutral → 0).

### 2) Class weights (by indicator family)
- Trend/MA = 0.30 (SMA/EMA/WMA/DEMA/ADX/DI/DM/SAR/AROON)
- Momentum = 0.25 (RSI/MACD/MACDEXT/MOM/ROC/ROCR/TRIX/CMO/ULTOSC)
- Oscillators = 0.15 (STOCH/STOCHF/STOCHRSI/WILLR/CCI/MFI)
- Volume/Flow = 0.10 (OBV/AD/ADOSC/BOP)
- Volatility/Regime = 0.20 (ATR/NATR/BBANDS bandwidth, TRANGE, DX)

### 3) Timeframe weights
- wD = 0.50, wH = 0.30, wW = 0.20.
- If Weekly technicals missing → wW=0.00 and print: `⚠ Weekly data unavailable — weekly weight reduced`.
- If Daily ADX≥25 and Hourly ADX<25: amplify D group by ×1.15; if Hourly ADX≥25 and Daily ADX<25: amplify H group by ×1.15.

### 4) Compute S (−1…+1)
- For each signal: signed_score = (+1 or −1) × class_weight × TF_weight.
- Sum all signed_scores, normalize by the max possible sum for present signals, clip to [−1, +1].
- Output: `Bias score S = <value> → {Bullish if S>0.25 | Neutral if −0.25≤S≤0.25 | Bearish if S<−0.25}`.
- Also list **Top 5 drivers by absolute contribution** as `name@TF`.

## Pre-market gap model (if available)
- g = |GAP| / ATR_D14. Classify: g<0.3 common; 0.3–0.8 breakaway candidate; >0.8 large.
- If D & W bullish and gap up → increase upside share; if both bearish and gap down → increase downside share.
- If OBV(H) contradicts gap direction → haircut adjustment by 40%.

## Forecast Engine (today only; OHLC from indicators + volatility)
We forecast `{open, high, low, close}` for **today’s daily bar**.

1) **Baselines**
   - O₀ = next_prediction_from_finnhub.daily.open if present else PCLOSE.
   - C₀ = Finnhub daily close if present else PCLOSE.
   - R_base = ATR_D14 × regime_factor, where regime_factor from ATR14/ATR50 on D:
     <0.8 → 0.8; 0.8–1.2 → 1.0; >1.2 → 1.2.
   - If BB bandwidth in lower 20% (D) → R_base ×= 0.85; if upper 80% → ×= 1.15.

2) **Apply bias S (directional tilt)**
   - CLOSE = C₀ + sign(S) × min(0.40×ATR_D14, |S|×0.60×ATR_D14).
   - OPEN: if pre-market exists, shift O₀ toward PREMKT_LAST by ±min(0.25×ATR_D14, |GAP|); else OPEN=O₀.

3) **Distribute range around O/C (bounded)**
   - Upside share u = 0.5 + 0.3×max(S,0) (clip 0.35–0.80)
   - Downside share d = 0.5 + 0.3×max(−S,0) (clip 0.35–0.80)
   - HIGH = max(OPEN, CLOSE) + u × R_base
   - LOW  = min(OPEN, CLOSE) − d × R_base

4) **Clamps & sanity**
   - HIGH ≥ max(OPEN,CLOSE); LOW ≤ min(OPEN,CLOSE)
   - (HIGH−LOW) ≤ 2.2×ATR_D14
   - If Weekly trend opposes S strongly (|S|>0.5), reduce the against-trend side by 20–40%.
   - If constraints fail, shrink u & d proportionally until valid.

5) **Weekly forecast (current week)**
   - Blend Finnhub weekly (if present) with Weekly signals (0.6/0.4). Clamp total range ≤ 1.8×ATR_W14 and do not violate already printed weekly highs/lows.
